### AC1 — 三個候選各有實際下載/請求的證據

- [ ] A(data.taipei 土地使用分區):實際下載,記錄格式、CRS、授權、更新日期、檔案大小
- [ ] B(OSM landuse/natural/leisure):實際取得 M1 bbox 範圍資料,記錄取得方式與時間
- [ ] C(正射影像):實際請求,記錄端點、是否需金鑰、授權條款出處
- [ ] 每一項來源不可用時**據實記錄**,不以文件描述代替

### AC2 — M1 bbox 內的覆蓋率與分類數(每個數字附指令)

- [ ] M1 bbox 面積基準值,來自 `contracts/constants/m1_area.json`(不另抄一份)
- [ ] A 的覆蓋率、分類數、各類面積
- [ ] B 的覆蓋率、分類數、各類面積
- [ ] **未被覆蓋的部分是什麼**(不只給比例,要給洞的分佈與大小)
- [ ] **headline 覆蓋率以兩種獨立方法量測並對帳**(精確聯集 vs 網格取樣)
- [ ] **任何回報「0」的量測附一個會回報非零的對照組**

### AC3 — A 的粒度問題(決定 A 能不能用)

- [ ] **明確回答:街廓內部有沒有細分?** 以實測的 polygon 尺寸分佈作答,非印象
- [ ] 河岸、公園、空地在 A 裡分不分得出來
- [ ] A 的幾何品質:自交、重疊、洞

### AC4 — B 的幾何品質與可重用性

- [ ] polygon 閉合性、重疊、無效幾何計數
- [ ] **能不能共用 FTP-29 既有的 bbox 裁切器** —— 以實測的 relation/way 佔比作答
- [ ] 授權:**引用 FTP-6 的結論**,不重新論證

### AC5 — C 的執行期外部依賴

- [ ] 可用性取樣 **≥20 次**,附時間戳與狀態分佈
- [ ] 能不能離線快取進 tile(授權是否允許)

### AC6 — 邊界(bbox 邊緣)

- [ ] 跨 bbox 邊界的 polygon 被裁切後,邊緣會不會出現空白帶
- [ ] 完全在 bbox 外的 polygon 不貢獻覆蓋(對照組)
